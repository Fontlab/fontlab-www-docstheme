# Next steps

The starter combines native MaterialX navigation with isolated Basecoat and
daisyUI components. Replace these pages with your own content.

While reading, Right and Alt+Right go to the next navigation page; Alt+Left goes
to the previous navigation page; Left goes back through browser history.

See the [complete setup guide](https://i.fontlab.com/fltheme26/).
