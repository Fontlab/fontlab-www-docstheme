In general the continuous text and navs should only use 3 font sizes (`xs` for captions, th, nav, footers; `sm` for tables, body; `md` for lead articles and possibly blockquotes). Note that we’ll in principle want to use separate font families, and mix serif with sans and with mono, and in that case, the emphasis or bold or mono fonts will need to have an additional font size like 1.05em or 0.95em to compensate for the different built-in x-heights of the families. Also, in general, we want to maintain a baseline grid, and we want to redefine the rem to be the base of that baseline grid, and therefore of the line-height (not of font-size). So in general, base line-height of the paragraphs etc. should be 2rem and line-heights of other elements should be based on rem. Smaller fonts in asides don’t need to keep the baseline grid. This is already done so in fltheme27
