# Vexy vector imagery

Vexy Lines pushes the theme harder than the writing guide. The imagery is
brighter, denser, and more kinetic; the docs chrome should hold it without
turning into a dark marketing landing page.

![Vexy Lines homepage image showing vector artwork made from source images](https://i.vexy.art/vl/landing/home-vexy-lines.jpg){ .fl-bleed }

The reading column stays narrow for comfort while an image can slip into the
right margin beside the text, keeping the words and the picture in the same eye
line instead of stacking them.

![Vexy Lines linear fill sample](https://res.cloudinary.com/fontlab/image/upload/c_limit,w_auto/f_auto,q_auto,dpr_auto/vw/68daa71678eede3413b20f4e_fill-linear.png){ .fl-aside }

Full-bleed images run from the left edge of the text all the way to the right
edge of the viewport, so a wide studio capture can breathe without being boxed
into the measure. Everything else — headings, paragraphs, lists — holds a
steady, readable line length.
