# FontLab web design system

The demo and reference site of fly-january, the documentation theme for FontLab and Vexy
sites built with ProperDocs and MaterialX. Every page here is rendered by the theme it
describes.

- [Tokens](theme/tokens.md): the palette, type roles, grid and sizes, drawn live from the
  `--fly-*` variables.
- [Configuration](theme/configuration.md): every `extra.fly` and page key, with examples
  the build validates.
- [Assets](theme/assets.md): the CDN copy of the theme for pages outside MkDocs.
- [Chrome](theme/chrome.md): FontLab, Vexy, no or custom global bars.
- [Field guide](start/index.md): design patterns and component specimens for FontLab web
  pages, with copyable Markdown and HTML.
- [Showcase](showcase/index.md) and [brand assets](brand-assets/index.md): product imagery,
  wordmarks and banners.

Writing rules live in the [FontLab writing guide](https://fontlab.dev/vexy-fontlab-writing-styleguide/fl1992mk/).
